# ohmy.design

Сайт студии. Статика, пятнадцать страниц, без фреймворков и сборщиков —
только два python-скрипта, которые готовят страницы к публикации.

## Что где

| Папка | Что это |
|---|---|
| `исходники/` | **здесь правим.** Страницы, картинки, шрифты страниц |
| `docs/` | результат сборки, отсюда GitHub Pages отдаёт сайт. Руками не трогать |
| `build-assets/` | Onest.ttf для картинок соцсетей |

## Сборка

```
python3 -m pip install Pillow      # один раз
python3 build-seo.py               # мета-теги, карта сайта, картинки соцсетей
python3 build-site.py              # раскладка в docs/
```

Порядок обязателен: второй скрипт берёт результат первого.
Правки в `docs/` затираются при следующей сборке.

## Публикация

GitHub Pages настроен на ветку `main`, папку `/docs`. После `git push`
сайт пересобирается сам за минуту.

Домен `ohmy.design` пока не подключён. Когда дойдут руки до DNS — поставить
`DOMAIN_LIVE = True` в `build-site.py`, пересобрать и запушить: файл `CNAME`
появится в `docs/` сам.

## Как устроены страницы

Каждая страница самодостаточна: свои стили в `<style>`, свои скрипты внизу.
Общего CSS-файла нет намеренно — страниц полтора десятка, и каждую можно
открыть и править изолированно.

Дизайн-система живёт в CSS-переменных в начале каждой страницы, тёмная
и светлая темы переключаются атрибутом на `<html>`. Шрифт — Onest с Google
Fonts, three.js с CDN на четырёх страницах с анимациями.

Подвал и счётчик Метрики — общие блоки на всех страницах. Правятся
скриптом-заменой сразу везде, а не руками по одной.
